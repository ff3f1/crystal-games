# Политика конфиденциальности игры «Бабушкин погреб»

Дата вступления в силу: 13 октября 2026 г.

1. Игра «Бабушкин погреб» (далее «Игра») не требует регистрации и не собирает имя, телефон, адрес электронной почты или другие данные, по которым можно напрямую установить личность игрока.

2. Прогресс игры (номер уровня, настройки звука) хранится только на устройстве игрока и никуда не передаётся.

3. В Игре показывается реклама Рекламной сети Яндекса (Yandex Mobile Ads SDK). Для показа и подсчёта рекламы SDK может получать рекламный идентификатор устройства, модель устройства, версию операционной системы, язык, IP-адрес и сведения о взаимодействии с рекламой. Обработка этих данных регулируется политикой конфиденциальности ООО «Яндекс»: https://yandex.ru/legal/confidential/

4. Рекламный идентификатор можно сбросить или отключить персонализацию рекламы в настройках Android.

5. Игра запрашивает доступ к интернету только для загрузки рекламы. Играть можно и без интернета.

6. Игра не предназначена для целенаправленного сбора данных о детях.

7. Вопросы по этой политике можно направить разработчику по адресу, указанному на странице Игры в RuStore.
