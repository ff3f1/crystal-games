# Арсенал рыбака — 0.5.1

Android-приложение Crystal Games для личной коллекции рыболовных снастей. Пакет production: `ru.crystalgames.arsenal`, debug: `ru.crystalgames.arsenal.test`. versionCode 7. Исходники в `android-arsenal/`.

## Последняя проверенная сборка
- Исходный коммит: fc85c1a5ae4798fc35cb6670cd603d44c7b37099 (26.11.2026 UTC).
- [Успешный CI и артефакты](https://github.com/ff3f1/crystal-games/actions/runs/45909631224).
- TEST: подписанный debug APK с тестовыми объявлениями и тестовой оплатой; устанавливается отдельно.
- PRODUCTION: неподписанный APK с реальными рекламными ID, оплата намеренно отключена. Не готов к загрузке в магазин без подписи.

## Текущее состояние
Коллекция, ссылки на товары, список желаний, комплекты, трофеи, связь трофеев со снастями, резервные копии. В 0.5.1: полноэкранное фото без обрезки, выбор обложки, Free — одно фото, PRO — до пяти фото и отключение рекламы. Существующие дополнительные фотографии сохраняются при потере PRO.

Yandex Mobile Ads SDK 8.7.0. Debug использует только demo-banner-yandex и demo-interstitial-yandex; release использует R-M-20514578-1, -2, -3. Один нативный баннер под WebView, скрывается на формах, трофеях, комплектах, фидерном таймере и настройках. Межстраничная только при переходе между рекламными разделами после 3 успешных действий и 5 минут с запуска или предыдущего показа. Без App Open и rewarded. Не кликать по собственным боевым объявлениям.

## Оплата
Разовая покупка PRO — 399 ₽. В debug используется тестовый endpoint, задаваемый через ARSENAL_LICENSE_URL. Release принудительно задаёт пустой LICENSE_BASE_URL. Не включать live без проверки платежей, восстановления, возвратов, чеков, актуальной оферты и политики конфиденциальности. Описание Python-сервера находится в license-server/README.md; Android-клиент обращается к PHP endpoint-ам, поэтому совместимость реально развёрнутого сервиса следует проверить отдельно.
