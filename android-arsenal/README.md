# Арсенал рыбака 0.3.0

Отдельное приложение ru.crystalgames.arsenal. Офлайн, без аккаунтов, рекламы и платных функций. Коллекция, до 4 фото на запись, товарные ссылки, хотелки с переносом купленного, комплекты, чек-лист, фидерные инструменты, фотоальбом трофеев, вес/длина/вид/дата/водоём, привязка к снастям, личные рекорды, экспорт JPG, резервное копирование JSON. Android хранит JSON атомарно во внутреннем файле (лимит 64 МиБ); фото сжимаются. В браузере сохраняется ограничение localStorage. Не загружать внешние сайты в WebView. Ссылки открываются отдельным браузером. Демо-изображения являются иллюстрациями. Сборка: Java 17, SDK 35, Gradle 8.9. Debug APK подписан временным ключом; при несовпадении подписи сначала экспортируйте данные старой версии, затем переустановите и импортируйте. Для RuStore потребуется стабильный ключ выпуска. РСЯ не подключена. Фоновый таймер не реализован. Тесты: node tests/smoke.cjs, CI Gradle assembleDebug + apksigner.
