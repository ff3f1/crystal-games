# Арсенал рыбака 0.4.0

Yandex Mobile Ads SDK 8.7.0, новый Maven репозиторий. Debug использует только demo-banner-yandex и demo-interstitial-yandex; release использует R-M-20514578-1, -2, -3. Один нативный баннер под WebView, скрывается на формах, трофеях, комплектах, фидерном таймере и настройках. Межстраничная только при переходе между рекламными разделами после 3 успешных действий и 5 минут с запуска или предыдущего показа. Без App Open и rewarded. Релиз не подписан, подпись для RuStore нужна отдельно. PRO и оплата не подключены. Проверить показ на реальном телефоне с тестовыми ID; не кликать по собственным боевым объявлениям. Политику конфиденциальности обновить перед публикацией.
