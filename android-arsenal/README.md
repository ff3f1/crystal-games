# Арсенал рыбака 0.2.0

Независимое приложение ru.crystalgames.arsenal. Офлайн, без сервера, пользовательские данные в localStorage. Все иллюстрации встроены в index.html. Функции: каталог снастей, фото, комплекты, хотелки, покупки/продажи, чек-лист, фидерный таймер, резервные копии, контроль расходников. Изображения являются иллюстрациями, а не фотографиями конкретных моделей товара. Сборка: Java 17, Android SDK 35, Gradle 8.9, gradle :app:assembleDebug. Отдельный тестовый ключ Android, не использовать для RuStore. Реклама не подключена; фоновые уведомления таймера ещё не реализованы. Перед переходом со старого тестового APK экспортировать данные: подпись может отличаться. Не хранить ключи подписи в репозитории.
