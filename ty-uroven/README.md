# ТЫ.УРОВЕНЬ 1.0

Офлайн RPG реальных действий для Android 8.0+. Отдельное приложение внутри монорепозитория Crystal Games. Другие игры и их Android-оболочка не меняются.

## Что работает

- Персонаж в полный рост: пол, три телосложения, семь натуральных оттенков кожи, три типа лица, пять причёсок, семь цветов волос, четыре аксессуара. Четыре игровых образа, открываемых за кристаллы и уровни.
- Уровни и четыре навыка растут за записанные действия. Ежедневные привычки, дела с результатом, цели с этапами, восемь достижений, пять глав острова. Пропуски не отнимают опыт.
- Финансы с начальным балансом **0 ₽**: доходы и расходы, редактирование и удаление, свои категории, месячные отчёты и диаграмма, общий и категорийные бюджеты, регулярные платежи с ручным подтверждением оплаты.
- Календарь дел, журнал питания с необязательными калориями, тренировки, вес с историей и графиком, аналитика последних 14 дней.
- Фотодневник с системным выбором изображений, локальным хранением, сравнением любых двух фото и удалением.
- Обучение, светлая/тёмная/системная тема, уменьшение движения, три оригинальные музыкальные темы, отдельная громкость музыки и эффектов, тактильный отклик.
- Атомарное сохранение IndexedDB, проверка конфликтов версий, миграция v0.8, проверка импортируемых данных, восстановление предыдущего состояния при повреждении. Резервная копия включает **все фотографии**.

Нет аккаунтов, рекламных SDK, аналитики, фиктивных друзей и рейтингов. В AndroidManifest нет разрешений, включая INTERNET. Выполнение действий подтверждает сам пользователь; датчики и банки не подключаются.

## Структура

`app/src/main/assets/core.js` — независимая модель и валидация.
`storage.js` — транзакции, миграции и резервные копии.
`app.js` — экраны и сценарии; `art.js` — слои персонажа и иконки.
`sound.js` — локальная музыка и эффекты, пауза в фоне.
`app/src/main/java/.../MainActivity.java` — локальный HTTPS-origin WebView, системные диалоги файлов, экспорт потоками, тактильный отклик и «Назад».

Рабочие исходники лежат в обычных файлах. Старый `ty-uroven-src.zip.b64` оставлен только как история v0.8 и новой сборкой не используется.

## Проверки и сборка

```sh
node --test ty-uroven/tests/core.test.cjs
python3 -m pip install playwright==1.56.0 pillow==12.0.0
python3 -m playwright install chromium
python3 ty-uroven/tests/ui_test.py work/ty-ui-results
cd ty-uroven
gradle assembleRelease assembleDebugAndroidTest lintRelease
gradle connectedDebugAndroidTest
```

Android SDK 35, JDK 17, Gradle 8.9. Для локальной проверки интерфейса: `python3 -m http.server --directory app/src/main/assets 8000` из `ty-uroven`.

GitHub Actions: `.github/workflows/ty-uroven-release.yml`. Собирает реальный APK, выполняет тесты модели и интерфейса, Android lint и инструментальные тесты на эмуляторе API 35 в авиарежиме. Артефакты: APK с SHA-256 и сертификатом, скриншоты интерфейса, результаты Android и снимки эмулятора.

## Подпись и обновление v0.8

Сборка для проверки подписана постоянным **открытым ключом разработки**, см. [signing/README.md](signing/README.md). Для RuStore нужен закрытый ключ владельца. Публикация в магазин не выполняется.

Исходный workflow v0.8 генерировал случайный debug-сертификат на каждом runner. Android не разрешает обновление с другой подписью. Перед удалением v0.8 экспортируй JSON, установи новый APK и импортируй копию. JSON v0.8 не включает фото: перед удалением сохрани оригиналы отдельно. Если обновление с совпадающей подписью возможно, записи и оригинальная база фото `ty-photos/shots` мигрируют автоматически.

## Данные и ограничения

Суммы хранятся в целых копейках. Награды имеют уникальные ключи; удаление и повторное добавление не дают повторный дневной бонус. Платёж создаётся по уникальной паре «план/месяц» и не списывается автоматически.

До 12 активных привычек и 240 фото. Фото уменьшаются до 1400 пикселей, метаданные EXIF не сохраняются. Импорт JSON до 160 МБ. Резервная копия не зашифрована: пользователь выбирает, где её хранить. Без резервной копии удаление приложения удаляет локальные данные. Восстановление предыдущего состояния предназначено для записей; для полной копии фотографий нужен экспорт.

Приложение не является медицинским сервисом, финансовым консультантом или системой проверки достоверности действий.
