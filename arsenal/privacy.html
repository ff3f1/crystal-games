Конфиденциальность

Информация о текущей тестовой версии Android-приложения «Арсенал рыбака» (ru.crystalgames.arsenal).

Данные коллекции

Пользователь самостоятельно вводит названия снастей, цены, сведения об уловах, водоёмах и фотографии. Они хранятся локально в приложении. Выбор изображений осуществляется через системный диалог Android. Приложение не отправляет фотографии и записи коллекции на собственный сервер.

Резервные копии и экспорт

Пользователь может сохранить JSON-копию коллекции или карточку трофея и самостоятельно выбрать место сохранения либо приложение для отправки. Экспорт может содержать личные фотографии и записи; храните такие файлы в безопасном месте.

Реклама

Бесплатная Android-версия содержит Yandex Mobile Ads SDK. Рекламная библиотека может обрабатывать технические данные устройства и сети, включая рекламные идентификаторы, согласно политике конфиденциальности Яндекса. Интернет используется для рекламы и открываемых пользователем внешних ссылок. Товарные ссылки открываются во внешнем браузере.

Удаление данных

Локальные записи можно удалить в приложении. Удаление приложения может привести к потере коллекции; предварительно сохраните резервную копию. Экспортированные файлы удаляются пользователем отдельно.

Платежи

Платёжная интеграция пока не запущена. Условия обработки данных покупателя будут опубликованы до её запуска.

Информационный сайт

На этих страницах нет форм сбора данных, аналитики или платёжных форм. Хостинг GitHub может обрабатывать технические журналы обращений согласно своей политике.
