# Рыбалка: Клюёт! — описание обновления для RuStore

## Кратко для пользователей
Крупное обновление графики и вываживания. Убрано переключение на рисованный стиль. Обновлены изображения 16 видов рыб, включая окуня и сома, и поплавок. Улучшена динамика рывков рыбы, изгиба удилища и сопротивления воды. Старые сохранения сохранены.

## Для модерации RuStore
Обновлены визуальные ресурсы рыб и поплавка, переработано отображение водоёмов и физика вываживания. Убрана настройка рисованной графики. Изменения не требуют новых разрешений; существующие сохранения и игровой прогресс поддерживаются.

## Проверка
Автоматические сценарии: заброс, поклёвка, подсечка, вываживание, улов, магазин, зима, сохранение, Камчатка, трофейные контракты и загрузка всех новых растровых спрайтов.

Важно: часть новых морских вариантов использует цветовые версии родственных спрайтов; анатомически точные фото каждого вида — задача последующей итерации. Фоны новых локаций временно используют растровые сезонные аналоги существующих водоёмов вместо SVG.
