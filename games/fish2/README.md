# Рыбалка: Клюёт! 2.0

Новая отдельная игра, в другом пакете Android: ru.crystalgames.fishing2.
Старая версия и её данные не изменяются.

Три биома — пруд, река и море. Летняя и зимняя версии каждого, всего шесть карт.
Разные виды рыб на разных участках, совместимость насадок, видимые признаки активности.
Поклёвка имеет две фазы: осторожная проба и настоящая потяжка.
Вываживание требует управлять нагрузкой на леску: подматывать, отпускать во время рывков, избегать провиса.
На замёрзшем пруду и реке можно бурить лунку и играть мормышкой; на зимнем море открыт берег.

Сейвы хранятся отдельно под ключом fishing2.progress.v1.
Звук — короткие синтезированные эффекты Web Audio; реклама отсутствует.

Структура: index.html + style.css + game.js. Стартовое меню содержит шесть карт.
APK строится workflow .github/workflows/fishing2-candidate.yml.

В исходной сборке используется шесть существующих фоновых фотографий из games/fish/assets/bg.
Авторские шесть новых фонов можно подключить, заменив одноимённые assets/scenes/*.webp, не меняя игру.
