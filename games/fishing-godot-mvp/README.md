# Рыбалка: Первый заброс — Godot 4 / alpha 0.3

**Отдельная 3D-игра на Android**, не затрагивает выпущенную «Рыбалка: Клюёт!» (`ru.crystalgames.fishing`). Код и тестовые сборки хранятся в ветке `prototype/fishing-godot-mvp`.

## Содержимое версии

- **Стартовое меню:** начать рыбалку, журнал, настройки, руководство; кнопка паузы прямо в игре
- **Настройки:** громкость звуков, чувствительность камеры, поле зрения, включение теней — сохраняются автоматически
- **Свободная прогулка от первого лица:** левый виртуальный джойстик, правый свайп; на ПК WASD и правая кнопка мыши
- **Живая рыбалка:** червь и блесна, заброс, поклёвка, подсечка, сопротивление, красная зона натяжения, подмотка, отпускание лески
- **Реальная поимка:** рыба показывается в 3D при подъёме из воды, затем в отдельном поворачивающемся окне трофея с весом
- **Виды:** карась, окунь, щука; щука теперь имеет собственную 3D-модель, а не чужую рыбу
- **Постоянный журнал уловов:** вид, вес, наживка и дата в `user://fishing_catches.json`
- **Звук:** процедурный озёрный фон, всплеск, поклёвка, работа катушки, успех/обрыв
- **Окружение:** берег с фототекстурой, лес, лодка, пирс, рыболовная стоянка, фотосканы камней и кустов, панорама реального озера

## Управление

На телефоне: **слева джойстик** для ходьбы; **справа свайп** для обзора; кнопка **Заброс** у воды, **Подсечь** при поклёвке, **Мотать** удержанием и отпустить при 80–90% натяжения. Кнопка **☰** — пауза.

На ПК: WASD/стрелки — ходьба, правая кнопка мыши — обзор, Space — заброс/подсечка, Tab — наживка, R — мотать, Shift — держать, Esc — пауза.

## Сборка и проверки

GitHub Actions: `Fishing Godot MVP — Android debug APK` при push в эту ветку создаёт **отладочный ARM64 APK**, скриншот запуска и скриншот экрана трофея. Перед экспортом:

1. Скачивает CC0 3D-модели и фототекстуры по лицензированным источникам (см. `assets/README.md`);
2. Устраняет glTF-расширение `KHR_mesh_quantization` в некоторых моделях;
3. Проверяет импорт и старт Godot без ошибок;
4. Выполняет сценарный тест меню → подсечка → пойманная рыба → трофей → журнал → настройки → пауза;
5. Экспортирует APK.

Для локального запуска установите Godot 4.5.1 и зависимости из `tools/fetch_assets.py`; в Actions всё устанавливается автоматически.

## Чего пока нет

Это **alpha 0.3**, не готовый коммерческий релиз. В игре пока один водоём, три вида рыбы, упрощённая борьба и нет инвентаря, магазина, заданий, смены погоды, поддержки RuStore/РСЯ и полноценной физики. Не тестировалось на конкретной модели телефона. Старую игру не удаляем и не публикуем этот пакет в магазин.
