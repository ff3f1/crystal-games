# Рыбалка: Первый заброс — Godot 4 MVP

Новый отдельный прототип **от первого лица**, никак не меняющий опубликованную «Рыбалка: Клюёт!».

## Игровой цикл
1. Поверни камеру свайпом (или мышью с зажатой правой кнопкой).
2. Выбери наживку: **Червь** для окуня/карася, **Блесна** для окуня/щуки.
3. Нажми **Заброс**, дождись всплеска и поклёвки.
4. Во время поклёвки нажми **Подсечь** до окончания окна.
5. В борьбе удерживай **Мотать**, отпуская при чрезмерном натяжении. **Удерживать** помогает быстрее сближаться, но добавляет нагрузку.
6. Подтяни рыбу ближе 2,5 м, избегая обрыва при натяжении 100% и ухода рыбы дальше 38 м.

Удобнее проверять на телефоне в горизонтальном режиме. Для PC: **Space** — заброс/подсечка/новый заброс, **R** — подмотка, **Shift** — удержание, **Tab** — наживка.

## Окружение
- Godot 4.5.1 / GDScript, режим **GL Compatibility**
- Без сторонних моделей и без платных ассетов; вода, лес, камни и снасти созданы процедурно
- Это **технический игровой прототип**, а не фотореалистичный рекламный скриншот; реальные модели и текстуры — отдельный этап
- Отдельный Android package `ru.crystalgames.fishingfirstcast`, не заменяет `ru.crystalgames.fishing`

## Сборка
GitHub Actions: `Fishing Godot MVP — Android debug APK`. После push в `prototype/fishing-godot-mvp` или ручного запуска получает **отладочный APK** в Artifacts. Сборка изолирована от старого `build.yml`.

Локально: открыть папку в Godot 4.5.1 и запустить `F6`/Play. Для Android экспорта нужны Android SDK, JDK 17 и export templates.

## Что пока намеренно НЕ сделано
- Нет РСЯ, доната, RuStore-публикации и переноса сохранений
- Нет настоящей симуляции лески/крючка, 3D-моделей рыб и снастей художественного качества
- Нет динамической экосистемы или сезонных карт
- Рыба и условия поклёвок упрощены; MVP проверяет ощущение базового цикла
