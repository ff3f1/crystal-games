# Рыбалка: Первый заброс — Godot 4 / MVP 0.2

Новый **отдельный 3D-прототип**: прогулка от первого лица по берегу, небольшая рыболовная стоянка, рыбалка и обзор окружения. Старое приложение `ru.crystalgames.fishing` не меняется.

## Что работает
- **Перемещение:** виртуальный джойстик слева (на ПК — WASD/стрелки). Нельзя бесконечно заходить в озеро; вдоль правого берега есть небольшой пирс.
- **Обзор:** свайп по правой/верхней части экрана (на ПК — правая кнопка мыши).
- **Заброс:** подойди к воде, выбери червя или блесну, нажми `ЗАБРОС`.
- **Поклёвка:** появляется окно подсечки на 1,75 сек, нажми `ПОДСЕЧЬ`.
- **Вываживание:** удерживай `МОТАТЬ`, отпускай при опасном натяжении. Дополнительная кнопка `ДЕРЖАТЬ` ускоряет подмотку, но повышает нагрузку.
- **Рыба:** карась, окунь, щука. Различаются силой и допустимыми наживками, пока без полного поведения экосистемы.
- **Сцена:** рельефный берег, фототекстуры земли, деревья и камни, рыболовная стоянка, деревянный пирс и лодка.

### ПК
`WASD` / стрелки — ходить; удерживать правую кнопку мыши — осмотреться; `Space` — заброс/подсечка/ещё заброс; `R` — мотать; `Shift` — держать; `Tab` — сменить наживку.

## Графика и ассеты

Вместо цилиндров и условных конусов игра скачивает перед импортом настоящие GLB-модели и 1K фототекстуры с лицензией CC0:

- Kenney Nature Kit — деревья, кусты, камни, растительность и коряги
- Quiet Lake Fishing — удилище, рыба, лодка, причал, снасти, лилии, камыш
- Poly Haven — фототекстуры мокрого песка и лесной почвы

Подробности и лицензии: `assets/README.md`.

**Это ещё НЕ фотореализм.** Часть исходных моделей стилизована. Следующий этап — оценить мобильный FPS, управление и художественное качество, затем заменить самые слабые модели и материалы.

## Сборка в GitHub Actions
Workflow `Fishing Godot MVP — Android debug APK` автоматически собирает APK при коммите в ветку `prototype/fishing-godot-mvp`.

1. Получает CC0 ассеты командой `python3 tools/fetch_assets.py`.
2. Приводит GLB из Quiet Lake к формату Godot командой `gltf-transform dequantize` — это нужно из-за несовместимого сжатия `KHR_mesh_quantization`.
3. Импортирует проект в Godot **4.5.1**, проверяет логи на ошибки и запускает headless smoke-test.
4. Экспортирует подписанный **отладочный ARM64 APK** с пакетом `ru.crystalgames.fishingfirstcast`.
5. Пытается создать реальный скриншот игрового кадра; сохраняет APK и превью в Artifacts.

Игра не публикуется в RuStore, не содержит рекламы и не заменяет существующую рыбалку.

### Локальный запуск
- Установить Python 3.11+, Node.js и `npm install -g @gltf-transform/cli@4.5.0`.
- Из папки проекта выполнить `python tools/fetch_assets.py`.
- Для 16 моделей в `assets/models` из Quiet Lake Fishing выполнить `gltf-transform dequantize input.glb output.glb`, затем заменить исходный GLB конвертированным.
- Открыть `project.godot` в Godot 4.5.1 и запустить сцену. Для Android экспорта дополнительно нужны Android SDK и JDK 17.

## Ограничения версии
- Рыбы пока моделируются упрощённой логикой, без настоящей гидродинамики или физического тела в воде.
- Нет свободного плавания, транспорта, инвентаря, магазина и сохранений.
- Нет гарантий стабильности на конкретном Android-устройстве до теста на нём.
